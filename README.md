# tda-lab-tema

Tema para los TDA Lab del alumnado de Tecnologías Digitales Aplicadas
(IES Santa Bárbara · La Felguera).

Se usa añadiendo **una línea** al `_config.yml` del Lab de cada alumno:

```yml
remote_theme: Moliw4n/tda-lab-tema
```

Y quitando la línea `theme:` si la hubiera.

Cualquier cambio que se haga aquí llega a todos los Labs en su siguiente commit.
